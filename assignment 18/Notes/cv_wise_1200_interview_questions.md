Questions 51–100: Python Basics
51. What is Python?
Python is a high-level, interpreted, general-purpose programming language known for readable syntax and a large ecosystem.

52. Why is Python popular?
Python is easy to learn, productive, cross-platform, and supported by many libraries and frameworks.

53. What are Python’s main features?
Readable syntax, dynamic typing, automatic memory management, object-oriented support, extensive libraries, and cross-platform compatibility.

54. Is Python interpreted or compiled?
Python source code is compiled into bytecode and then executed by a virtual machine. It is commonly called an interpreted language.

55. What is dynamic typing?
Dynamic typing means a variable’s type is determined at runtime and can change during execution.

56. What is strong typing?
Strong typing means Python does not silently combine incompatible types.

57. What is a variable?
A variable is a name that refers to an object in memory.

python
name = "Omar"
age = 25
58. What are Python data types?
Common types are integer, float, string, Boolean, None, list, tuple, set, and dictionary.

59. What is an integer?
An integer is a whole number without a decimal part, such as 10 or -5.

60. What is a float?
A float represents a number with a decimal part, such as 3.14.

61. What is a string?
A string is an immutable sequence of characters.

python
message = "Hello"
62. What is a Boolean?
Boolean has two values: True and False.

63. What is None?
None represents the absence of a value.

64. What is type casting?
Type casting converts a value from one data type to another.

python
number = int("10")
65. What is implicit conversion?
Implicit conversion happens automatically when Python safely converts a type.

python
result = 5 + 2.0  # float
66. What is explicit conversion?
Explicit conversion is manually converting a value using functions such as int(), str(), or float().

67. What is type()?
type() returns the type of an object.

python

68. What is id()?
id() returns an object’s identity during its lifetime.

69. What is isinstance()?
isinstance() checks whether an object belongs to a particular class or type.

python

70. What is ==?
== compares the values of two objects.

71. What is is?
is checks whether two references point to the same object.

72. Difference between == and is

73. What is a list?
A list is an ordered, indexed, mutable collection.

python

74. What is a tuple?
A tuple is an ordered, indexed, immutable collection.

python
point = (10, 20)
75. What is a set?
A set is an unordered collection of unique values.

python

76. What is a dictionary?
A dictionary stores values using unique keys.

python

77. List vs tuple
Lists are mutable and usually used for changing collections. Tuples are immutable and useful for fixed collections.

78. List vs set
Lists preserve order and allow duplicates. Sets contain unique values and are optimized for membership checks.

79. Tuple vs set
Tuples are ordered and immutable. Sets are unordered and mutable, although their elements must be hashable.

80. Dictionary vs list
A list accesses values by numeric index. A dictionary accesses values by key.

81. What is mutable data?
Mutable data can be changed after creation, such as lists and dictionaries.

82. What is immutable data?
Immutable data cannot be changed after creation, such as strings, numbers, and tuples.

83. Which objects are mutable?
List, dictionary, set, and most user-defined objects are mutable.

84. Which objects are immutable?
Integer, float, Boolean, string, tuple, and frozenset are immutable.

Slicing extracts part of a sequence.

Negative indexing accesses items from the end.

python

94. What is an argument?
